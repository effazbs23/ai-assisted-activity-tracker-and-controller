How the ERPNext MCP Server Works

The assistant already knows the sales side of ERPNext. The MCP server teaches it everything else, as the person who is chatting, and only after they say "yes" to changes.

1. The idea in one minute

A salesperson chats with a Telegram bot. The bot has a small set of built-in tools for sales work: leads, quotations, sales orders and daily activities.

Before this server existed, a question like "list all warehouses" got the answer "I don't have a tool for that."

The MCP server (named frappe) is a second toolbox. It lets the assistant read and change any other ERPNext record: stock, accounting, projects, notes and more. MCP (Model Context Protocol) is just a standard way for an AI app to plug in extra tools.

4. What it can do

Nine tools, split into read: runs immediately and write: needs your yes.

list_docsREAD

List records of any type. "List all warehouses."

get_docREAD

Open one record in full.

count_docsREAD

Count records. "How many projects do we have?"

describe_doctypeREAD

Learn a record type's fields so the AI fills in new records correctly.

run_reportREAD

Run a saved ERPNext report, for example stock balance.

create_docWRITE

Create a new record. "Create a note titled…"

update_docWRITE

Change fields on an existing record.

submit_docWRITE

Submit a draft so it becomes final.

cancel_docWRITE

Cancel a submitted record.

Requests it fulfils (examples)

You sayWhat happens
"list all warehouses"Reads and shows the 5 warehouses straight away.
"list all customer groups"Reads and shows the groups straight away.
"how many projects do we have?"Counts them straight away.
"list all users"Shows the people in the system (read-only).
"create a note titled …"Shows exactly what it will do, then waits for yes.

Anything that is not sales and that your ERPNext account is allowed to touch is fair game.

What it will never do

  • Delete anything. There is no delete tool.
  • Change security settings. Roles, permission rules, API keys, system settings and logs are blocked. Users can be viewed but never changed.
  • Run a write without your yes.
  • Work around your permissions. See the next section.

5. It acts as you, not as an admin

So the assistant can never see or do more than you can in ERPNext. A real example from testing: asking "how many employees do we have?" as manager was refused, because ERPNext itself says that role cannot open Employee records.

On top of ERPNext's rules, the server adds two more: only CONFIRM_CALLERS may submit or cancel Sales Orders, and only ITEM_CREATORS may create items.

6. The "yes" gate for changes

What it looks like in Telegram

create a note titled MCP test note with the content hello from telegram
I will run frappe.create_doc with {"data": {"content": "hello from telegram", "title": "MCP test note", "doctype": "Note"}}
Please reply yes to confirm or no to cancel.
yes
Done. MCP tool frappe.create_doc ran. Note … saved.

7. Under the hood

  • It is a small program (erpnext/mcp_server/frappe_server.py) that the API starts by itself the first time a fallback is needed, and restarts if it stops.
  • They talk through plain text lines on standard input and output (JSON messages). Three message types: say hello, list your tools, run this tool.
  • Reads vs writes are decided by a label on each tool (readOnlyHint). Cancel is also marked destructiveHint.
  • Safety limits: list size is capped, answers are cut at 4,000 characters, and a call that takes over 60 seconds is dropped.
  • No new setup: the server reuses the same ERPNext address and per-person keys the app already has.

8. Turn it on

Add one line to erpnext/.env, then restart the API from the erpnext folder:

MCP_SERVERS=frappe=venv/bin/python -m mcp_server.frappe_server

Leave it empty and the assistant works exactly as before, sales tools only.

10. Good to know

  • It only kicks in when the sales tools cannot help. The AI has to say it cannot do the request first.
  • The sales safety rules do not apply here. Fuzzy-name suggestions and "price comes from ERPNext" belong to the built-in tools. For MCP requests ERPNext's own validation and your roles are the safety net.
  • The AI provider matters. Heavy use can hit the provider's rate limit, and the bot then says "The assistant is unavailable right now."
  • Pending confirmations live in memory. A restart forgets anything still waiting for a yes.
